# Tkinter Login Interface

## About the Project

This project is one of my personal programming projects, originally created as a way to practice and apply the lessons we discussed during the previous semester, particularly **Python Tkinter**.

I developed a simple login and registration interface to revisit my knowledge of Tkinter and practice working with GUI elements such as frames, labels, entry fields, buttons, and other widgets.

Although this project was created several months ago, I decided to upload it to GitHub as part of my personal programming portfolio rather than let the work go unused.


## Project Purpose

The main purpose of this project is to refresh my previous knowledge, practice GUI development, and regain familiarity with Python Tkinter.

This is not intended to be a complete or production-ready login system. It was built primarily to focus on the interface and the implementation of basic Tkinter components.


## Features

- Simple login and registration interface
- Full name, age, and address input fields
- Gender selection using radio buttons
- Username and password fields
- Password masking

 ## Project Limitations

Please expect some imperfect coding practices, inconsistencies, or areas that could be improved. This project reflects my learning progress at the time it was developed.

It does not include a database, backend authentication, or actual account registration functionality. Its primary focus is the graphical user interface (GUI).

Despite its limitations, the interface is functional, and revisiting this project helped me recover and reinforce some of the knowledge I gained during the previous semester.
